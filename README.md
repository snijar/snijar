# Егор

Разрабатываю веб-приложения, backend и Telegram-адаптеры. Мне интересны API-интеграции и автоматизация прикладных задач.

## Основной проект

### [Booking Assistant](https://github.com/snijar/booking-assistant)

Новое демонстрационное приложение для записи клиентов. Выбор услуги и времени, создание, просмотр, отмена и перенос записи; административный список и отдельный Telegram-адаптер.

**Python · FastAPI · SQLite · JavaScript**

- Занятость защищена транзакциями и уникальным индексом базы.
- Повтор запроса учитывает пользователя и содержимое действия.
- Доступ к чужой записи проверяется на сервере.
- Основное демо запускается без Telegram-токена и платных API.

[Код и запуск](https://github.com/snijar/booking-assistant#посмотреть-и-запустить) · [Реальные скриншоты](https://github.com/snijar/booking-assistant/tree/egor-portfolio/docs/screenshots) · [Проверки CI](https://github.com/snijar/booking-assistant/actions)

Это пет-проект, созданный с помощью ИИ. Ограничения и технические решения описаны в репозитории. Публичного backend-деплоя нет; Telegram проверен локальными тестами адаптера, реальная доставка сообщений не заявляется.
